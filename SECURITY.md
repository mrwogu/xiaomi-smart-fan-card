# Security Policy

## Supported versions

| Version              | Supported |
| -------------------- | --------- |
| Latest `0.x` release | Yes       |
| Older releases       | No        |

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities.

Use [GitHub private vulnerability reporting](https://github.com/mrwogu/xiaomi-smart-fan-card/security/advisories/new).

Include:

- Affected version or commit
- Reproduction steps
- Expected security impact
- Suggested mitigation, when known

Never include Xiaomi tokens, Home Assistant credentials, private URLs, or
personal entity data in a report.

## Scope

This policy covers the Xiaomi Fan Card source code, release bundles, GitHub
workflows, and published HACS artifacts. Third-party Home Assistant
integrations and Xiaomi services are outside project control.
