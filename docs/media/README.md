# README media slots

The root README reserves these filenames for the HACS landing page:

- `card-overview.png` for a clean dashboard screenshot
- `card-controls.gif` or `card-controls.webm` for a short control animation

Before publishing media, redact entity names, hostnames, locations, device
identifiers, tokens, and personal dashboard information. Keep files small
enough for the HACS panel and prefer compressed screenshots and short clips.
